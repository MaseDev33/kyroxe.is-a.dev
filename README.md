# Kyroxe portfolio

A game-inspired developer portfolio built with Vite.

## Run locally

```bash
npm install
npm run dev
```

The admin route and login are configured through `VITE_BLOG_ADMIN_PATH`, `VITE_BLOG_ADMIN_USERNAME`, and `VITE_BLOG_ADMIN_PASSWORD` in `.env`. The editor stores posts in the browser's local storage, so it is a front-end drafting tool rather than a secure publishing backend. Netlify deploy settings live in `netlify.toml`.
